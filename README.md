# Rajdeep Chatterjee - Personal Portfolio 🚀

A highly advanced, visually stunning, and interactive personal portfolio website showcasing my skills, projects, and achievements as a Full Stack Developer.

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://rajdeep-portfolio.vercel.app/) <!-- Replace this link with your actual Vercel link once deployed -->

## 🌟 Key Features
- **Premium Dark Mode**: Sleek dark aesthetic with neon cyan and purple accents.
- **Glassmorphism Design**: Modern frosted glass effects on cards, modals, and the navigation bar.
- **Interactive 3D Elements**: Smooth tilt animations on images and project cards.
- **Dynamic Lightbox**: Fully responsive and animated lightbox for viewing certificates in high resolution.
- **Functional Contact Form**: Direct message delivery powered by Formspree API.
- **Responsive Architecture**: Perfectly scaled for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack
- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Library**: [React.js](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Interactions**: [React-Tilt](https://www.npmjs.com/package/react-tilt)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Forms**: [Formspree](https://formspree.io/)

## 🚀 Running Locally

To run this project on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rajdeep372/rajdeep-portfolio.git
   cd rajdeep-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
